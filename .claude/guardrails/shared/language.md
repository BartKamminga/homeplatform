# Language

- **Conversations with Claude**: Dutch.
- **Code**: English — variables, functions, classes, components, file names. Also in existing Dutch files as soon as you work in them.
- **UI texts end users see** (labels, buttons, texts): preferably English, same regime as code — new texts in English, convert existing Dutch texts as soon as you work in them.
- Comments, commit messages, roadmap items and changelog stay in Dutch (the project management language).
- Existing Dutch code and UI are not converted in bulk retroactively.
