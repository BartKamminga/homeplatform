# Versioning

Use **MAJOR.MINOR.PATCH** (semantic versioning):

| Level | When | Example |
|---|---|---|
| **MAJOR** | New application or site live, infrastructure migration, architecture change | launch → `v4.0` |
| **MINOR** | Significant feature, admin extension | new feature → `v4.1` |
| **PATCH** | Bug fix, small tweak, deploy fix | config fix → `v4.0.1` |

Version number unclear? Ask first.
